# Home, account actions and motion owners

Use [UI rules](../../architecture/web-ui.md) and [named features](../../README.md#home) before adding effects. Existing components serve real data/actions; library demos and downloaded specimens are not product capabilities.

## Home composition and text

[HomePage](../../../apps/web/src/pages/home-page.tsx) / [CSS](../../../apps/web/src/pages/home-page.css), [HomeHeroSection](../../../apps/web/src/features/home/components/home-hero-section.tsx) / [CSS](../../../apps/web/src/features/home/components/home-hero-section.css) own discovery surface, responsive heading/search/video and editorial News. [HomeStudyNotebook](../../../apps/web/src/features/home/components/home-study-notebook.tsx) uses actual document/announcement queries; [useHomeNews](../../../apps/web/src/features/home/hooks/use-home-news.ts) combines actual NEWS/BLOG responses. Unmounted mock widgets do not supply current Home values.

[MaskedHeading](../../../apps/web/src/components/react-bits/masked-heading.tsx) is the actual free `MaskedHeading-TS-CSS` equivalent of requested JS/CSS. Measured SVG word masks/GSAP reveal use current Vietnamese type, mesh tokens and native semantic text/geometry. Native fallback remains readable for reduced motion/unsupported masks; decorative graphics are aria-hidden. Reveal is once per mount after startup release, not per refetch/theme change; drift pauses offscreen/hidden/startup, and scoped observers/tweens revert on unmount/StrictMode. About alone retains [BlurText](../../../apps/web/src/components/react-bits/blur-text.tsx). Tech Text/Electric Logo are absent; the [logo](../../../apps/web/src/components/ui/logo.tsx) stays static.

Home supplies two explicit text lines: “Tài nguyên học tập” then “OLYMPIC HUMG”. MaskedHeading measures the same native line/word geometry for SVG and fallback; the narrow-screen font adjustment keeps the brand on line two without losing Vietnamese text. [PublicFooter](../../../apps/web/src/layouts/components/public-footer.tsx) is the actual bottom-of-site owner: discovery, contact, social/theme sections stay visible on mobile and desktop, with no disclosure step. Other application accordions are unaffected.

[SmoothTab](../../../apps/web/src/components/kokonutui/smooth-tab.tsx) decorates real Radix tabs in Home/Toolkit with a measured selected indicator; Radix owns arrows/Home/End/focus/panels. Preserve resize cleanup, wrapping labels,44px controls, immediate content and Toolkit URL/history. [SpotlightCard](../../../apps/web/src/components/react-bits/spotlight-card.tsx) decorates only Home's real room/GPA anchors; focus/touch works without hover and reduced motion keeps a static cue. No carousel/stock content or new Home album collection is mounted.

## Home and auth video owners

[HomeHeroSection](../../../apps/web/src/features/home/components/home-hero-section.tsx) keeps heading/search beside one decorative ambient window on desktop, stacking on smaller screens. [CinematicScene](../../../apps/web/src/components/ui/cinematic-scene.tsx), [media owner](../../../apps/web/src/components/ui/cinematic-media.ts) and [original source attribution](../../../apps/web/public/videos/SOURCES.txt) retain original day/light and night/dark assets/posters. Muted inline looping autoplay where supported; no Home player controls/captions/keyboard stops. Reduced motion, blocked autoplay and media failure retain a static poster. Home opts out of startup media preparation so search/readiness remains usable.

[AuthCardLayout](../../../apps/web/src/layouts/auth-card-layout.tsx), [WelcomeLayout](../../../apps/web/src/layouts/welcome-layout.tsx) and [auth-video CSS](../../../apps/web/src/layouts/auth-video-layout.css) retain original desktop scene/form rails: registration right, other guest forms left. Mobile mounts no video; no visible motion toggle. Theme/hidden/offscreen/unmount pause and current auth preparation/fallback remain. The static404 variant is separate.

## Account and article actions

[UserDropdown](../../../apps/web/src/features/auth/components/user-dropdown.tsx) adapts [Kokonut ProfileDropdown](../../../apps/web/src/components/kokonutui/profile-dropdown.tsx) with real current identity/actions via existing Radix menu. One workspace entry uses getDashboardRoute for admin/lecturer/student; profile/security/Home/sign-out retain authorization and existing lifecycle. Guest sign-in stays in public header. Wrapped identity, scrollable short-screen menu, keyboard/Escape/focus and44px actions remain; no template billing/identity actions.

[ShareButtons](../../../apps/web/src/features/post/components/share-buttons.tsx) adapts [Kokonut SocialButton](../../../apps/web/src/components/kokonutui/social-button.tsx) to actual article URL/title: encoded platform anchors, capability-gated native share and copy feedback. Open by pointer intent/click/touch/keyboard; Escape returns trigger, outside/blur closes, hidden controls are inert. Preserve44px action geometry, quiet native cancellation and real failures. External effects occur only on activation; no decorative no-op platforms or automatic posting.

## Loading opacity and lifecycle

[index.html](../../../apps/web/index.html), [loading CSS](../../../apps/web/src/app/loading-screen.css) and [startup-preloader](../../../apps/web/src/app/startup-preloader.ts) keep initial status/reload/no-JS readable. Real task/query/font state releases interaction immediately; a180ms opacity exit is nonblocking, with no fake progress/minimum delay/hold. Terminal query errors reveal feature recovery. Context/subscription cleanup releases root/inert/scroll on final unmount; focus moves only if it was in the disappearing loader.

[PageLoading](../../../apps/web/src/components/ui/page-loading.tsx) / [RouteSuspense](../../../apps/web/src/router/route-suspense.tsx) own later scoped loading. Existing GSAP is used; React Bits FadeContent was a reference, not a stock ScrollTrigger application wrapper. Reduced motion stays static; no query-refetch entrance or extra loading gate.
